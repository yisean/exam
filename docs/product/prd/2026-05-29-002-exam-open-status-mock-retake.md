# PRD：开放/关闭状态、模拟/正式考试与补考次数

## 1. 背景与问题

当前题库（`el_repo`）、试题（`el_qu`）没有「可用 / 停用」概念：废弃或暂不启用的题库与试题无法从组卷中排除，只能删除，存在数据丢失风险。考试（`el_exam`）也没有「模拟练习 vs 正式考核」的区分，正式考核无法限制重复作答次数——员工可无限次刷正式考试，削弱考核效力。

本特性补齐三项控制能力：**开放/关闭状态**、**模拟/正式考试类型**、**正式考试补考次数**。来源为原型阶段确定的产品决策（[`functional-spec.md` §8](../functional-spec.md)）。

## 2. 目标与非目标

### 目标
- 题库 / 试题 / 考试可标记为「开放」或「关闭」，关闭项从相关位置隐藏而非删除，保留数据。
- 考试区分「模拟」与「正式」：模拟不限次数供反复练习，正式受控计入成绩。
- 正式考试可设补考次数上限，约束员工重复作答。

### 非目标
- 软删除 / 回收站机制（关闭 ≠ 删除，但本特性不提供恢复式删除流程）。
- 状态变更的审计日志 / 操作历史。
- 模拟考试成绩的单独统计分析视图。

## 3. 目标用户与角色

| 角色 | 在本特性中的职责 |
| --- | --- |
| 超级管理员 / 老师（`sa`/`teacher`） | 在题库/试题/考试列表中切换开放-关闭状态并按状态筛选；创建考试时选择模拟/正式类型，为正式考试设补考次数 |
| 学员（`student`） | 仅看到开放的考试；按考试类型与补考次数限制参加考试 |

## 4. 功能需求

### 4.1 开放 / 关闭状态
- **F1** 题库、试题、考试均新增「开放类型」：开放 / 关闭。新建默认开放。
- **F2** 组卷时，**关闭的题库与试题不进入可选范围，也不会被随机抽取**。
- **F3** **关闭的考试在学员端不可见**（列表不展示、入口不可达）。
- **F4** 管理端列表可按状态筛选，并对单个对象一键开放 / 关闭。
- **F5** 关闭仅影响可见性与组卷参与，**不删除数据**；已使用关闭题/库的历史试卷不受影响。

### 4.2 模拟 / 正式考试
- **F6** 考试新增「考试类型」：模拟考试 / 正式考试。新建默认正式。
- **F7** **模拟考试不限考试次数**，供员工反复练习。
- **F8** **正式考试受补考次数限制**，计入正式成绩。

### 4.3 补考次数
- **F9** 创建/编辑**正式考试**时可设补考次数（如 2 次）。
- **F10** 学员对正式考试的作答次数达到「1 次正考 + N 次补考」上限后不可再考。
- **F11** 模拟考试该项不适用，显示为「不限次数」。

## 5. 关键用户流程

**管理员配置**
1. 题库/试题列表 → 对某项点「关闭」→ 该项从组卷与（考试场景下）学员端隐藏。
2. 创建考试 → 选类型「正式」→ 填补考次数；或选「模拟」→ 次数项置灰为「不限」。

**学员应考**
1. 学员端只列出开放的考试。
2. 模拟考试可反复进入；正式考试在达到补考上限后入口不可用。

## 6. 验收标准

- **AC1（F2）** 关闭某题库后，新建考试组卷时该题库不出现在可选项，已配置规则的随机抽题也不再抽到其题目。
- **AC2（F3）** 关闭某考试后，学员端在线考试列表不再出现该考试。
- **AC3（F5）** 关闭一道已被历史试卷引用的试题，历史试卷与成绩展示不受影响。
- **AC4（F7）** 模拟考试可被同一学员多次进入作答，不受次数限制。
- **AC5（F8/F10）** 正式考试设补考 2 次，学员完成 1 次正考 + 2 次补考后，第 4 次进入被拒绝。
- **AC6（F11）** 将考试类型从正式切为模拟后，补考次数项显示为「不限次数」且不再限制作答。

## 7. 成功指标

- **人工判分占比 / 题库可维护性**——关闭代替删除，减少误删返工。
- **正式考试有效性**——正式考试的人均作答次数落入「1 + 补考上限」区间，无超额刷分。
- **模拟练习使用量**——模拟考试被反复练习的次数（反映练习闭环价值）。
