# 原型构建规范（供并行构建参考）

> 目标：用纯静态 HTML + `assets/app.css` 复刻云帆考试系统全部现有模块 + 新增「预约考试」原型，多页面可点击、发给客户演示。**不依赖任何外部 CDN / JS 库**。

## 通用规则

1. 每个页面是独立 HTML，`<head>` 引入 `<link rel="stylesheet" href="assets/app.css" />`。
2. **样式只用 `app.css` 里已有的 class**（btn / card / table / tag / form-item / input / select / steps / tabs / dialog / pagination / stat-card / qu-* / tree-node 等）。需要微调用内联 `style`。不要引入新 CSS 文件。
3. **不写复杂 JS**。允许少量内联 `<script>` 做：标签页切换、打开/关闭 `.dialog-mask`（加/去 `open` class）、答题选项高亮。页面间跳转一律用 `<a href="xxx.html">`。
4. 顶部统一放原型提示条（从 `dashboard.html` 复制 `.proto-bar`）。
5. 中文界面，措辞专业、贴合企业内训考试场景。用下方示例数据，让客户觉得真实。
6. 表格操作列用 `<a class="btn-text" href="...">`；主操作按钮用 `.btn.btn-primary`。

## 两种外壳（直接从参考页复制）

- **管理端外壳**：见 `dashboard.html` —— 复制 `.proto-bar` + `.app-wrapper` 里的 `<aside class="sidebar">`（含 4 组菜单）+ `.topbar`。把当前页对应的 `.menu-item` 加 `active`，并删除 dashboard 上的 active。`.topbar .crumbs` 改成当前页面包屑。右上角用户 `超管A`，链到 `profile.html`。
- **学员端外壳**：侧边栏只有「在线考试」一组，菜单项：在线考试(`my-exam.html`)、我的成绩(`my-records.html`)。logo 同管理端。右上角用户 `张三`。
- **助理端外壳**：侧边栏只有「考试预约」一组，菜单项：考试预约(`assistant-booking.html`)。右上角用户 `李助理（技术部）`。

学员/助理外壳照管理端 `.sidebar` 结构改菜单项即可。

## 示例数据（统一口径）

- 公司/部门树：北京云帆互联科技有限公司 → 技术部(后端组/前端组/产品组/测试组)、人事部、财务部、客服部(客户一组/客服二组)
- 用户：admin/超管A(超级管理员,技术部)、person/张三(学员,人事部)、李助理(考试助理,技术部)、王老师(老师)
- 角色：超级管理员(sa)、老师(teacher)、学员(student)、考试助理(assistant)
- 题库：【云帆】演示题库、安全生产题库、ISO9001 质量管理题库、新员工入职题库
- 题型：单选题、多选题、判断题、简答题；难度：普通 / 较难
- 示例试题（来自真实库）：
  - 单选：「我国最北面的城市是哪个？」选项 铁岭/齐齐哈尔/沈阳/漠河(正确)
  - 多选：「以下哪些是中国的特别行政区？」香港(对)/澳门(对)/珠海/重庆
  - 判断：「咖啡的故乡是非洲吗？」正确(对)/错误
- 示例考试：【云帆演示】考试(总分100,30分钟,及格60)、2026 Q2 全员安全生产考核(指定部门)、新员工入职考试(预约考试)、ISO9001 测评(已结束)

## 「预约考试 / 时间段」新功能要点（务必体现）

- 一场考试可配置**多个时间段**，每段有：开始时间、结束时间、**开放类型**（不限人员 / 指定部门 / 预约考试）。
- 「指定部门」类型：管理员勾选若干部门。
- 「预约考试」类型：设**可预约部门数上限**；由考试助理预约。
- 全局「提前可见」时长（如 5/10 分钟）可在系统配置里设。
- 助理端：看到含「预约考试」时段的考试 → 每个时段显示 起止时间 / 已约部门数 / 上限 / 状态 → 可「预约」（代表本部门含下级）、「取消」、「改约」；约满显示「已满」，时段已开始显示「已截止」。每部门每场考试只能约一个时段。
