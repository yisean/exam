# 云帆培训考试系统（开源版）功能方案

> 基于现有代码（`exam-vue` 前端路由 / API）与数据库脚本（`docs/ops/install/数据库脚本.sql`）分析整理。
> 文档日期：2026-05-29　｜　代码版本：`yf-exam-lite` v1.9.2
> 定位：**面向企业内部员工、自有题库、私有部署的在线培训考试系统**。

---

## 一、系统概览

| 项目 | 说明 |
|------|------|
| 技术栈 | SpringBoot + Shiro + JWT（后端） / Vue2 + Element-UI（前端，本仓库） / MySQL |
| 部署形态 | 私有部署，单体应用，前后端分离 |
| 核心场景 | 企业内训考核：建题库 → 组卷 → 定员发布 → 在线作答 → 自动判分 → 错题训练 → 成绩统计 |
| 角色模型 | 超级管理员（sa）、老师（teacher，路由预留）、学员（student） |

---

## 二、角色与权限

权限基于 Shiro + JWT，前端通过角色动态加载路由（`exam-vue/src/router/index.js`）。

| 角色 | 标识 | 可见模块 |
|------|------|----------|
| 超级管理员 | `sa` | 全部：在线考试 + 考试管理 + 系统设置 |
| 老师 | `teacher` | 考试管理（题库/试题/考试）—— 路由已预留，种子数据未启用 |
| 学员 | `student` | 在线考试、我的成绩、错题训练、个人资料 |

> 说明：种子数据中仅有 `sa`、`student` 两个角色；`teacher` 在路由 `roles: ['sa','teacher']` 中已声明，属于可启用但默认未配置的角色。

## 四、核心能力详解

### 4.1 题库与试题
- **题型**：单选题、多选题、判断题、简答题（`qu_type`：1/2/3/简答 `saq`）。
- **难度**：普通、较难（`el_qu.level`：1/2）。
- **富内容**：题干、选项均支持图片（`image` 字段）；支持整题解析与单选项解析（`analysis`）。
- **题库关联**：试题与题库多对多（`el_qu_repo`），一题可复用于多个题库。
- **导入导出**：试题支持批量导入导出（管理端按钮，便于批量建库）。

### 4.2 组卷引擎（`el_exam_repo`）
按「题库 + 题型」维度配置组卷规则，每条规则定义：
- 单选题：数量 + 单题分值
- 多选题：数量 + 单题分值
- 判断题：数量 + 单题分值
- 简答题：数量 + 单题分值

考试可关联多个题库，系统按规则**随机抽题组卷**，题目与选项随机排序，降低作弊风险。

### 4.3 考试发布与开放范围（`el_exam`）
- **开放范围**（`open_type`）：1 完全公开 / 2 指定部门 / 3 定员（指定人员）。
- **时间控制**：是否限时（`time_limit`）、开始/结束时间、总时长（分钟）。
- **判分线**：总分、及格分（`qualify_score`）。
- **状态机**：考试状态（`state`）控制未开始/进行中/已结束。

### 4.4 作答与判分（`el_paper` / `el_paper_qu` / `el_paper_qu_answer`）
- 每次作答生成一份试卷快照（题目、选项、排序均落库）。
- **客观题**（单选/多选/判断）自动判分；**主观题**（简答）记 `subj_score`，需人工/规则处理（`has_saq` 标记含简答题）。
- 记录用户用时、客观分、主观分、最终得分、是否答对。

### 4.5 成绩与错题闭环
- **考试汇总**（`el_user_exam`）：按用户×考试记录考试次数、最高分、是否通过。
- **错题本**（`el_user_book`）：交卷后错题自动入本，记录错误次数、最近错误时间。
- **错题训练**：学员可针对错题反复练习，形成"考试→错题→训练"的学习闭环。

### 4.6 定时任务（`QRTZ_*`）
集成 Quartz 调度框架，用于考试到期自动收卷/关闭、状态流转等定时逻辑。

## 六、现状小结与潜在增强方向

**现有能力已覆盖**：题库管理、组卷、定员考试、在线作答、自动判分、错题训练、组织/权限管理、系统配置。

**面向"企业内部员工考试"可考虑的增强方向**（待与你确认优先级）：
1. **简答题判分流程**：当前简答题落 `subj_score`，缺明确的人工阅卷/批改界面。
2. **统计分析**：部门/岗位维度的成绩分布、及格率、薄弱知识点报表。
3. **题型扩展**：填空题、组合题、案例题等。
4. **培训课程联动**：商业版有"课程/在线学习"，开源版暂无 → 可补"学完即考"。
5. **防作弊增强**：切屏检测、人脸/摄像头核验（依赖 `tracking` 库已引入）、随机题序已具备。
6. **证书/积分**：通过考试发证书、积分商城（商业版功能）。

## 八、原型阶段新增的产品决策

除「预约考试」外，原型阶段还对现有模块确定了以下增强（已体现在原型，待开发）：

### 8.1 开放/关闭状态（题库、试题、考试）
- **题库、试题、考试**均增加「开放类型」：开放 / 关闭。
- **关闭的对象在其他位置不可见**：
  - 组卷时，**关闭的题库与试题不出现在可选范围**，也不会被随机抽取。
  - **关闭的考试**在学员端看不到。
- 管理端可在列表中筛选状态，并对单个对象一键开放/关闭。

### 8.2 模拟考试 / 正式考试
- 考试增加「考试类型」：**模拟考试 / 正式考试**。
- **模拟考试不限考试次数**，供员工反复练习。
- **正式考试有补考次数限制**，受控计入正式成绩。

### 8.3 补考次数
- 在创建/编辑考试时，可为**正式考试**设置**补考次数**（如补考 2 次）。
- 模拟考试该项不适用，显示为「不限次数」。

> 以上为现有模块的扩展性产品决策，与第六节「潜在增强方向」并列；落地实现方案待 `ce-plan` 阶段细化（含数据库字段、组卷过滤逻辑、考试次数校验等）。
