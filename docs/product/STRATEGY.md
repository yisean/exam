# 云帆培训考试系统（开源版） Strategy

## Target problem

企业要对员工做内训考核，但考核内容往往涉密（安全规程、内部制度、岗位机密），
不能托管到问卷星、钉钉等公有云 SaaS——考核数据必须留在企业自己手里。

## Our approach

以**极致轻量的私有部署**取胜：一个 jar 包 + 一个 MySQL 就能跑起来，无需复杂中间件、
无需专职运维。轻量到能"装完即忘"，让没有专业 IT 团队的中小企业也能把涉密考核系统装进自己内网。

## Who it's for

**Primary（组织者）：** 企业里的考核组织者（HR / 培训负责人 / 被指派的部门主管）——
他们雇用本系统每季度组织一次面向员工的考核：建库、组卷、定员发布、自动判分、看谁通过。
低频（季度一次）意味着系统必须傻瓜化、免维护，到点拿出来就能开考。

**Secondary（员工）：** 参加考试的员工——要的是"打开就能考、考完看到分数和错题"。

## Key metrics

- **考试完成率（核心）** - 发下去的考试中员工实际完成的比例；衡量员工能否顺利考。
- **部署到开考时长** - 从下载 jar 到第一场考试跑起来的耗时；验证"轻量好部署"是否成立。
- **季度复用率** - 装了之后下个季度仍继续使用的企业比例；反映真实价值，能升能降。
- **人工判分占比** - 需人工介入批改的题目比例；越低说明自动化越好。

> 指标这节访谈较简，后续可再打磨（尤其是数据从哪采集）。

## Tracks

### 多角色考试流程

围绕三类角色把考试全流程做扎实：**老师**（出题、管理题库与考试）、**学生**（参加考试、
看成绩、练错题）、**考试助理**（预约/安排考试场次，组织协调）。其中"考试助理"角色与
"预约考试"能力为规划新增（当前代码仅有 sa/teacher/student）。

_Why it serves the approach:_ 角色职责清晰，组织者每季度低频使用也能各司其职、快速上手。

### 轻量私有部署与免维护

一键部署、最少依赖、装完免维护——降低私有部署门槛，让数据不出内网成为现实。

_Why it serves the approach:_ 这是"轻量好部署"打法的直接载体，也是低频组织者愿意自建的前提。

### 员工答题与错题闭环

顺滑的在线答题体验、自动判分、错题本与错题训练，形成"考试→错题→训练"闭环。

_Why it serves the approach:_ 直接拉动核心指标"考试完成率"，保证员工真正考得完、学得到。
